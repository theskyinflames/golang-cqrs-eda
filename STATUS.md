# Status

Claude Code plugin that teaches Claude the CQRS / EDA / DDD conventions from
[theskyinflames/cqrs-eda](https://github.com/theskyinflames/cqrs-eda) and copies
a modernized version of that library into Go projects (copy-in model).

## Done

- [x] Choose skills over CLAUDE.md, and the copy-in model over importing the library
- [x] Modernize the library into copy-in templates (`skills/cqrs-eda/assets/template`):
      generic typed handlers, `slog`, `UnitOfWork` middleware, stdlib `uuid`, no external deps,
      and fixes for dropped publish errors, middleware ordering, zero-value panics and bus deadlocks
- [x] `scripts/install.sh`: copies the platform, rewrites imports, falls back to
      `google/uuid` on Go 1.24–1.26, refuses Go < 1.24 and existing installs, runs vet + tests
- [x] `SKILL.md`: rules with rationale, layout, workflows, review checklist
- [x] `references/patterns.md`, generated by `dev/gen-patterns.sh` from the compiled
      `dev/sample-shop`
- [x] Plugin manifest, marketplace manifest, MIT license (relicensed from GPL-3.0)
- [x] Quality evals (`evals/cqrs-eda`): 3 evals with fixtures, `check.py` for mechanical checks
- [x] Eval iterations 1–3 and the fixes they drove (see [Eval results](#eval-results))
- [x] Rule 0: every use case is a command or query in the application layer;
      eval checks 1.15, 2.13 and 3.12 added for it
- [x] Trigger eval set: 20 queries (10 should trigger, 10 near-misses), reviewed
- [x] Trigger eval fixed (`evals/cqrs-eda/trigger/`, see its README): upstream skill-creator
      only counted the skill if it was the first tool call, ran queries in `~` with no Go
      code, and ran parallel queries in one shared project where each session saw several
      identical skill copies. Run results and traces are in `trigger/results/`.
- [x] Trigger description: applied iteration 2 of the Sonnet 5.5 loop
      (`trigger/candidates.json`). Measured on Sonnet with the fixed eval (2026-10-04,
      `trigger/results/2026-10-04-sonnet-isolated/`):

      | Queries passed | 17/20 | 20/20 |
      | Should-trigger runs that loaded the skill | 30/30 | 30/30 |
      | Near-miss runs that loaded the skill | 7/30 | 3/30 |

      Queries run inside a CQRS shop fixture, which makes near-misses look more related
      than in a random project. Earlier numbers under `results/2026-10-04-sonnet/` were
      measured with the broken eval and aren't comparable.
- [x] Push to GitHub (`theskyinflames/golang-cqrs-eda`)
- [x] Note in the old `theskyinflames/cqrs-eda` repo (still GPL-3.0) pointing to this plugin
